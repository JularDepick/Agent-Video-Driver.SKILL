# 分镜表与确认门

复制本文件到工作目录的 `storyboard.md` 填写, 填完先给用户看, 拿到同意再渲染.
背景与偏好写到 `prompts/brief.md`, 本文件只装"这一条片子的时间与画面决策".

## 一, 启动确认门 (必须先问)

- [ ] 已告知预估 token 消耗量级
- [ ] 已告知中间帧数量与磁盘占用
- [ ] 已告知渲染耗时量级
- [ ] 已告知全量渲染与最终合成会长时间吃满 CPU, 开发机上会明显卡顿
- [ ] 已告知本会话只做这一条视频
- [ ] 已确认配色: 用户给定主色与底色, 或从三到五个色相方向里选定一个 (风格库的调色板只作兜底参考)
- [ ] 已确认是否分批次编码, 分批就写明批数
- [ ] 已确认确认模式: 逐步确认 (每阶段停下给用户看) 或 一次确认 (确认后一口气做完)
- [ ] 需求确认单已问完并落进 `prompts/requirements.md` (画幅, 时长, 帧率, BPM, 配乐引擎等一次问完, 中途不再追加)
- [ ] 用户已明确同意开始

确认模式的选择依据: 事实与审美需要用户发言权的题材 (知识解说, 品牌故事) 用逐步确认; 判据客观的题材 (数据动画, 片头片尾) 可以一次确认跑完.
两种模式下, 开头预览这一个交付节点都不可省略, 见第六节.

## 一之二, 合成确认门 (每次跑重活前各走一次)

启动确认门只覆盖一次, 全量渲染与最终合成各自还要再确认一次, 记录在下面:

| 门 | 探测命令 | 探测结论 | 采用的限额 | 用户是否同意 |
|:---:|:---|:---|:---|:---:|
| 全量渲染前 | `python scripts/resources.py --for render --frames <帧数>` | | 并行进程数 | |
| 最终合成前 | `python scripts/resources.py --for encode --frames <帧数> --out-dir <产物目录>` | | 线程数 / preset / 优先级 | |

填写判据:

- 探测结论要写清核数, 当前负载, 可用内存, 目标盘剩余空间, 以及是否建议拦截
- 判定为空间不足或负载过高时不要开工, 把影响与选项报给用户让他决策
- 未获同意时只跑 `assemble.ps1 -ProbeOnly`, 不做任何编码
- 强行开工要显式加 `-Force`, 并把理由写进本节

## 三, 段落表

| 序号 | 起止秒 | 起止小节 | 段落标题 | 演示内容 | 元素入场拍 | 转场手法 |
|:---:|:---:|:---:|:---|:---|:---|:---|
| 00 | 0.0 到 7.2 | 0 到 3 | 标题 | 主标题, 副标题, 信息卡 | 1 / 3 / 5 | 柔光扫过 |
| 01 | 7.2 到 16.8 | 3 到 7 | | | | |
| 02 | | | | | | |
| 03 | | | | | | |
| 04 | | | | | | |
| 05 | | | | | | |
| 06 | | | | | | |
| 07 | | | | | | |
| 08 | | | | | | |
| 09 | 末尾 4.8s | 末 2 小节 | 片尾 | 结论, 来源, 制作信息 | 1 / 3 / 5 | 压黑 |

填写判据:

- 段落边界必须落在小节线上, 段落长度取 2 到 6 个小节的整数倍
- 每段内部至少有一次数值或图形变化, 纯静态段落不超过 2 秒
- 任意两段的内部结构不得完全相同, 全片结构一样会让观感变平
- 元素入场一律写拍号, 不写秒数; 把 BEAT 改掉时所有元素应当整体跟着挪
- 关键句 (揭晓, 反转, 末屏) 要落在音乐能量发生变化的那一小节第一拍

## 六, 交付节点

| 节点 | 内容 | 交付路径 | 通过标准 |
|:---:|:---|:---|:---|
| 配色与风格样图 | 一个配色与风格组合方向出两张样图: 标题卡与典型演示屏, 都附底色与强调色色值 | 例 `temp/style_title.png`, `temp/style_demo.png` | 用户看完给出回执, 认可配色与风格 |
| 开头预览 | 渲染开头约 10 秒的带音轨连续成片, 停在拍点上不在半句切断 | 例 `temp/preview_intro.mp4` | 用户看完给出回执, 认可风格与节奏 |
| 完整成片 | 全片 | 例 `out/成片.mp4` | 第七节全部通过 |

交付纪律: 每一行都要先交出文件路径, 等用户回执, 之后才提问或进入下一决策.
静态样图只能判断配色与版面; 节奏, 转场与音画同步必须看带音轨的连续样片.
