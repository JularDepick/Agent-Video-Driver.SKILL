# 需求确认单

复制本文件到工作目录的 `prompts/requirements.md`, 在阶段 0 之前一次问完, 得到答复后写进"已确认值"一列再往下走.
允许整单一次回复, 也允许回复"全按默认"取每一项的缺省; 确认之后进入阶段 0 与阶段 1, 中途不再追加需求类问题 (品牌三问除外, 见下).
改动单内任何一项都要按 SKILL.md 第一节的连带代价表先报价再动手.

## 客观判据不进本单

PSNR 不低于 45dB, 集成响度 -16 到 -14 LUFS, 真峰不高于 -1.0 dBFS, 音轨 AAC 384k, 段落落小节线, 纯静态段落不超过 2 秒是验收底线, 不是选项, 不问不改.

填写判据:

- 画幅给自定义宽高时先算中间帧体积预估并报价, 超过短边 1080 的两档 (例如 4K) 时明确告知渲染与体积的代价倍数
- 帧率与时长定了之后, 中间帧张数 = 时长 x 帧率, 直接把它与磁盘占用报给用户
- 配色是用户主权项: 无论用户从哪个选项进, 最终都要落到明确的色值; 风格库的调色板只作兜底参考, 不得替用户默认套用
- 第 1 到 5 项定了之后不要中途反问, 阶段 3 的分镜与阶段 4 的配乐都从本单取值
