# 风格与配乐单

复制本文件到工作目录的 `prompts/style-and-score.md`, 在阶段 3 交给用户.
本单是审美决策的唯一入口: 风格, 配色, 配乐取向, BPM 与确认模式都在这里定, 立项单里不问这些.

交付顺序不能反: **先把三张候选样图与两到三段配乐试听做出来, 给出文件路径, 等用户看完听完, 再请他挑**.
只给文字描述, 或者只给一张静态帧就要用户选方向, 都不算交付.

## 一, 风格候选 (三张, 差别要看得出来)

| 候选 | 牌 id | 档 | 完整度 | 样图路径 | 配乐取向 | 推荐理由 (绑题材) | 用户选定 |
|:---:|:---:|:---:|:---:|:---|:---|:---|:---:|
| A | | 响 / 稳 / 轻 | 详细牌 / 指导牌 / 总览牌 | 例 `temp/style_A.png` | | | |
| B | | | | | | | |
| C | | | | | | | |

- 三张候选各出一张**同内容**的样图 (同一个标题或同一句正文, 只换风格), 拼在一起交给用户, 底板明度与强调色必须差别看得出来
- 三张里至少留一张轻的档; 全给响的等于没给选择
- 推荐理由要与题材绑定 (为什么这张适合这条片), 不给风格打分, 不说"这张更高级"
- 要说明每张的完整度: 详细牌有配色十六进制与参数, 指导牌有一节实现指导, 总览牌只有总览表一行, 选它要先自己定参数
- 取候选: `python scripts/style_lottery.py --pick 3 --write <项目目录>`; 用户挑定后 `--style <id> --write <项目目录>` 落成 `STYLE.md`
- 用户点名了风格或参考片时跳过候选, 但样图仍要出: 用点名的风格渲一张, 请用户确认参数对不对
- 挑定之后才写分镜; 中途换牌要重出候选与样图, 并按连带代价表报价

## 二, 配乐试听 (两到三段, 每段 8 秒左右)

| 片段 | 引擎 | 音色取向 | 片段路径 | 用户倾向 |
|:---:|:---|:---|:---|:---|
| A | `orchestra.py` 管弦乐 | | 例 `temp/score_A.wav` | |
| B | `music.py` 键盘与电子 | | | |
| C | 用户自备音乐 (经 `beats.py` 反推拍表) | | | |

- 试听片段用同一条拍表合成, 只换音色取向, 这样差别只来自音色
- 用户可以听完再改取向; 选定后整条配乐按该取向合成, 换取向要重做配乐并按连带代价表报价
- 用户自备音乐时走 `beats.py` 反推拍表, 画面服从该拍表, 不走本技能的合成引擎

## 三, 配色 (用户主权项)

| 路径 | 内容 | 已确认值 |
|:---:|:---|:---|
| 用户直接给 | 主色与底色的十六进制 | |
| 从色相方向挑 | 三到五个差别看得出来的方向, 每个方向给底色, 主色与一个强调色 | |
| 兜底色板 | 牌堆里该牌的调色板, 只在用户没有偏好时使用 | |

- 配色必须落到明确的色值才算确认; 风格库的调色板只作兜底参考, 不得替用户默认套用
- 用户给主色时按主色推整套色: 底色取主色的暗端, 强调色取邻近色相, 并把值写进分镜表与 `STYLE.md`
- 亮场与暗场的对比度要在样图上就能看出来, 样图附底色与强调色的色值

### 牌面配色与用户配色的合并 (两者都要用时按这个顺序)

牌面的调色板分两类角色, 合并时各归各位, 不要整盘替换也不要整盘照抄:

| 角色 | 包含 | 合并规则 |
|:---:|:---|:---|
| 身份色 | 主色, 强调色, 高亮色 | **用户配色接管**, 牌面只提供它们该出现在哪些位置 |
| 结构色 | 底色, 面板底, 网格线, 分隔线, 次级文字 | 由用户底色按牌面给的**明度关系**派生, 色相可以完全不同 |

- 色相距离在 30 度以内时, 用户强调色可以直接替换牌面强调色, 其余参数不动
- 色相距离超过 60 度时不要只换色值: 按用户色重排"邻近色加补色"的关系, 避免两块高饱和色并置
- **明度档位变了就要逐条核对实现指导**: 牌面若是深底发光, 而用户给白底, 那么 glow, bloom, 内亮边, 低透明度白填充这几样会集体失效, 必须换成投影与描边; 这一步不能省, 实测"普鲁士蓝底与深空蓝金"能直接相容正是因为两者同属深底
- 对比度底线不随配色合并而放宽: 正文不低于 4.5:1, 交互控件边框不低于 3:1, 亮场与暗场各测一次
- 合并结果落盘时在 `STYLE.md` 顶部记一行来源, 例如"底色与强调色来自用户, 面板与网格层次来自牌面", 改片时才好追溯

## 四, BPM 与确认模式

| 项 | 具名路径 | 推荐 | 已确认值 |
|:---:|:---|:---|:---|
| BPM | 慢 80 到 90 / 中 100 / 快 120 到 140 / 用户指定 | 按题材与风格取, 每小节拍数固定 4/4 | |
| 确认模式 | 逐步确认 / 一次确认 / 放手一条龙 | 逐步确认 | |

- 放手一条龙意味着后面不再停: 必须在分镜表里记下每个岔口选了什么与为什么, 并在交付时一并汇报
- BPM 与时长一起定死拍表; 改 BPM 或时长会让拍表, 配乐, 排程与全部帧作废, 按连带代价表报价

## 填写判据

- 三张候选样图的文件路径必须写进本单并明确告诉用户, 没有路径就没有交付
- 配乐试听片段要能听出取向差别; 只给一个片段等于没给选择
- 配色, 风格, BPM 三项确认齐了才允许写分镜与合成配乐
- 本单确认后进入阶段 3 的分镜收尾 (段落表与贯穿线索) 与阶段 4
