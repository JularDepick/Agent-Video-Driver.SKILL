# 配乐引擎

引擎有两套, 共用同一份时间栅格与 CLI 约定:

| 脚本 | 音色取向 | 适用 |
|:---:|:---|:---|
| `scripts/orchestra.py` | 管弦乐 (弦乐群, 圆号, 单簧管, 长笛, 竖琴, 拨弦, 定音鼓, 人声) | **默认推荐**, 不刺耳且层次多 |
| `scripts/music.py` | 电子与键盘 (毛毡钢琴, pad, 正弦低音, 软边击, 钟琴) | 需要更轻更现代的听感时 |

底层 DSP 基元在 `scripts/dsp.py`, 新写音色库请从它取 `lp_fft` `hp_fft` `bp_fft` `reverb` `bus_compress` `warm_master` 等.

全参数化:

```
python scripts/orchestra.py <时长秒> <BPM> <输出文件名> <切点逗号分隔> [输出目录]
python scripts/orchestra.py 108 100 score_orch.wav "7.2,16.8,26.4,36,50.4,64.8,79.2,91.2,103.2"
python scripts/music.py     108 100 score_nobel.wav "7.2,16.8,26.4,36,50.4,64.8,79.2,91.2,103.2"
```

第 3 个参数是纯文件名, 目录走第 5 个参数 (缺省 audio), 写成带目录的名字会拼出重复路径.
`orchestra.py` 另有两个选项: `--sr <采样率>` 降采样合成 (低内存机器防 OOM, 编码阶段再用 ffmpeg 上采样回 48k), `--chunk <秒数>` 分段写盘 (每段独立合成与母带后 concat 拼接, 段界落在切点上). 两者可同用; 分段路线的代价见 workflow.md 阶段 4 的说明.

切点必须与画面段落边界完全一致, 这是卡点的根.

## 时间栅格

拍 = 60/BPM 秒, 小节 = 4 拍. 常用两档:

| BPM | 拍 | 小节 | 适配 |
|:---:|:---:|:---:|:---|
| 120 | 0.5s | 2.0s | 30s 以内的燃向宣传片 |
| 100 | 0.6s | 2.4s | 90s 以上的讲解与纪录片 |

小节数取整, 末尾留 2 到 3 秒做收束, 时长就能精确到帧.

## 音色库

| 音色 | 实现要点 | 风格 |
|:---:|:---|:---|
| `soft_kick` | 正弦扫频 62 到 102Hz, 0.17s 衰减, 无 click 无失真 | 纪录片 |
| `kick` | 正弦扫频 46 到 176Hz, 加瞬态 click 与 tanh 饱和 | 燃向 |
| `rim` | 噪声经 4 阶带通 200 到 900Hz, 加 180Hz 短音 | 纪录片 |
| `snare` `clap` | 噪声包络加音体, 带通到 7kHz | 燃向 |
| `hat` `shaker` | 高通噪声, 短衰减 | 燃向, 慎用 |
| `piano` | 正弦加 2/3/4 次谐波且高次衰减更快, 6ms 起音 | 通用 |
| `pad` | 每个和弦音三路失谐正弦, 0.9s 慢起, 低通 900Hz | 通用 |
| `sub_bass` | 正弦加二次谐波, 低通 260Hz | 通用 |
| `bell` | 基频加 2 倍与 3 倍分音, 长衰减, 低通 3.2kHz | 段落头点缀 |
| `fm_piano` | 载波加指数衰减的调制指数, 调制比 3.01, 再叠 5Hz 慢颤音, Rhodes 味; 实现见 `scripts/dsp.py` | 主奏与点缀 |
| `swell` | 噪声经 4 阶带通随时间上移, 1.9s 渐强 | 段落切换前 |
| `thump` | 低频正弦 34 到 64Hz 扫频 | 段落切换点 |

调制比取 3.01 而不是整数 3, 是为了让边带不与基频重合, 听感偏铃而不是偏木. `music.py` 从第 4 小节起用它铺一条主奏线, 只落在小节头与第 3 拍, 不铺满, 免得盖住琶音.

## 编排骨架

1. 开头 2 小节只留 pad 与钟琴, 让观众先看清标题
2. 每小节一个和弦, 走 8 小节循环 (本次用 Cmaj7 Am7 Fmaj7 G6 Cmaj7 Em7 Fmaj7 G6)
3. 低音落在 1 与 3 拍, 软底鼓也在 1 与 3 拍, 软边击在 2 与 4 拍
4. 钢琴走八分音符琶音, 1 拍与 3 拍加重
5. 每 4 小节句首加一枚钟琴
6. 每个切点前 1.9s 起 swell, 切点处落 thump 加钟琴
7. 结尾 2.2s 渐弱加一次收束和弦

## 混音与母带 (关键)

顺序固定, 由 `scripts/dsp.py` 的 `warm_master` 一次跑完:

| 步 | 做什么 | 为什么排在这个位置 |
|:---:|:---|:---|
| 1 | 底鼓侧链闪避: 每个底鼓点让音乐与低音衰减到 0.72 再 50ms 内恢复 | 在音色平衡之前, 闪避量才不被后续滤波改写 |
| 2 | 总线压缩: 用 0.09 到 0.45s 时间常数的包络, 阈值 0.16 到 0.22, 超出部分按 0.5 到 0.55 次幂衰减 | 需要脉冲的音乐时间常数不得短于 0.3s, 否则压缩器会把拍点压平 |
| 3 | 音色平衡: 220 到 900Hz 提 0.4 倍做温暖区, 3kHz 以上每倍频程压 0.45 倍, 6kHz 以上再压 0.35 倍, 最后 4.6kHz 三阶低通 | 高频处理是防刺耳的关键, 不要为了亮而省掉 |
| 4 | 去除 32Hz 以下隆隆声 | 小喇叭放不出来, 只会吃掉动态余量 |
| 5 | 软限幅 `soft_clip`: 小信号单位增益, 逼近上限时按 tanh 压缩 | 只压瞬态, 主体电平不动, 比整体降增益更能保住响度 |
| 6 | 首尾淡入淡出 `fade_edges` | 必须在归一化之前 |
| 7 | 归一化 `normalize` | 排在淡入淡出之后; 反过来的话开头的瞬态会顶掉整首的天花板, 整片偏轻 |
| 8 | 过采样真峰压制 `true_peak_limit` | 编码器看的是采样之间的峰, 不是采样点 |

第 8 步的三点设计理由:

- 在 4 倍过采样域压, 压的才是编码器真正看到的采样间峰值
- 压完要低通回原带宽再抽取, 否则抽取会把压出来的高频折回可听带内
- 压完再按实测真峰等比回抬到目标天花板, 于是主体被抬回来而真峰正好落在 -1.0 dBTP; 这一步是线性的, 不会引入新的削波

`warm_master` 返回 `(立体声, 报告字典)`, 报告里有 `peak_db` `true_peak_db` `true_peak_ok` 三项, 两套引擎都把真峰打进输出行, 未压住时会标 `[真峰未压住]`.

磁带味与底噪是可选的润色, 不在这条链里, 由引擎自己加: `tape_wow` 用缓慢游走的读指针做音高漂移(千分之二以内听不出跑调), `vinyl_bed` 垫稀疏爆点与高通嘶声(电平压在千分之五以内, 超过会盖住弱奏段落).

## 客观判据 (必须达标)

用 `python scripts/check_audio.py <文件名> <BPM>` 检查:

| 指标 | 目标 | 含义 |
|:---:|:---:|:---|
| 拍点峰值比 | 按引擎分档: 管弦乐版高于 1.3, 键盘与电子版高于 1.8 | 有节奏 |
| 折叠包络起伏 | 大于 0.35, 峰值相位落在 0 附近 | 听得出拍点, 这是主判据 |
| 自相关 | 小节长度处 r 大于 0.5 | 结构清晰 |
| 低频 20 到 90Hz 占比 | 10% 到 30% | 超过 50% 会浑浊; 下限不是 20%, 见下面的说明 |
| 高频 2 到 8kHz 占比 | 低于 35% | 超过 45% 会刺耳 |
| 温暖区 0.3 到 0.8kHz 占比 | 高于 3% | 低于 1% 会发干发薄 |
| 谱心 | 键盘与电子音色版 600 到 1500Hz; 管弦乐版 300 到 550Hz | 超过 2000Hz 一定刺耳; 管弦乐版偏暗是刻意的, 不要照键盘版的区间去调 |
| 峰值 | 采样峰值不高于 0.95, 真峰不高于 -1.0 dBTP | 留余量给 loudnorm; 真峰由母带链最后一步压住, 引擎会把实测值打进输出行 |

低频那一行的下限本来写的是 20%, 但引擎自己的频段目标表写的是 9.9%, 两处互相矛盾 (与拍点峰值比那条是同一类问题); 实测重新量过之后按 10% 到 30% 写, 判据以实测为准而不是以旧文字为准.

三条量测纪律:

- **谱心区间必须按引擎区分**. 键盘与电子音色版实测 1045 到 1488Hz, 管弦乐版整片实测 317Hz (逐 10 秒窗口在 249 到 385Hz 之间波动), 两者的目标区间根本不同; 拿键盘版的 600 到 1500Hz 去要求管弦乐版, 只会把母带的高频架推上去, 立刻变刺耳.
  管弦乐版的谱心会被持续层电平牵动: 弦乐与主奏压低之后谱心掉到 296Hz (低于窗口下限), 靠空气层 `air_noise` 从 0.010 提到 0.014 抬回 317Hz; 调持续层电平之后必须重看这一项, 不要再靠推高频架去补
- **拍点峰值比必须按引擎分档, 而且它不是主判据**. 键盘与电子的拍点靠强瞬态, 管弦乐靠配器层次加拨弦地基, 两者能到的水平根本不同: 同一套母带链下, 管弦乐版实测 1.39, 键盘与电子版能到 1.8 以上. 拿 1.8 去要求管弦乐版, 只会把母带的高频架推上去, 结果是刺耳 (本文件另一节也警告过这一点). 管弦乐版的判据是 1.3, 键盘与电子版是 1.8; **更贴近听感的主判据是折叠包络起伏大于 0.35**, 拍点峰值比贴不到门槛时先看那一项
- **单调性判据要整片量测**. 它按每 10 秒一段统计 RMS 起伏, 片段短于约 40 秒时只有两三个窗口, 起伏倍数没有意义; 24 秒的试听片段量出 1.72 倍不代表成片不达标, 108 秒整片才是有效样本
- **拍点峰值比会随片段长度变化**. 管弦乐的引子段本来就不放拨弦与定音鼓, 取开头 24 秒会把这几个小节算进去, 比值被拉低; 量测时要覆盖到有节奏层的段落, 或者按整片量

## 拍表与能量的独立验证

`check_audio.py` 是在**已知 BPM** 的前提下验证节拍, 它不做节拍检测. 要有独立证据, 用另一个工具从音频反推:

```
python scripts/beats.py audio/score.wav --bpm 100 --json temp/beats.json
```

两条用途:

| 用途 | 判据 |
|:---:|:---|
| 验证自产配乐 | 测出的 BPM 与配乐常量误差在 1 BPM 内, 首拍相位误差在 40ms 内, 网格拟合平均残差在 15ms 内; 超差说明配乐拍点没落在设计位置 |
| 反推用户自备音乐 | 测出的 BPM, 首拍, 下拍直接交给 `timing.py` 与画面模块当拍表用, 先给用户确认一遍 |

它还会输出**逐小节响度变化清单**: 每个小节相对前两小节的 dB 差, 大于等于 +3dB 标 louder, 小于等于 -3dB 标 thinner.
这份清单就是"揭晓与反转该放在哪一小节"的依据, 也是十段式力度弧线是否真的落到音频上的检查:
若全片一个变化点都没有, 说明力度弧线只写在代码里没起作用.

## 用户自备音乐

用户给一首现成的音乐时, 先反推拍表, 再看它的段落结构够不够用. 不够用时可以剪, 但只能在整小节边界上剪.

```
python scripts/beats.py music.mp3 --json temp/beats.json            # 反推拍表
python scripts/loops.py music.mp3 temp/beats.json --len 8 14        # 找可无缝重复或剪掉的小节
python scripts/cutmusic.py music.mp3 temp/beats.json --bars 5-21 14-30 75-end -o audio/music-edit.wav
python scripts/beats.py audio/music-edit.wav --json temp/beats-edit.json   # 复测, 判据与源一致
```

`loops.py` 比较各小节的平均对数谱, 给出两个清单:

| 清单 | 含义 | 判据 |
|:---:|:---|:---|
| 可重复区间 | 第 i 小节与第 i+L 小节相似, 于是第 i 到 i+L-1 小节可整段重复 | 相似度不低于 0.99 通常听不出接缝 |
| 可剪接点 | 第 i 与第 j 小节相似, 于是剪掉第 i 到 j-1 小节之后接得上 | 同上 |

`cutmusic.py` 的接缝做法与"直接拼接"的区别: 输出总长等于各段长度之和, 所以小节线落在精确的累加位置上, 拍网格不被破坏; 每个接缝处取源音乐里**紧接在下一段之前**的那一小段素材, 用等功率交叉淡化混进上一段的末尾. 于是接缝两侧在源文件里本来就相邻, 听不出剪过, 而下一段的第一个采样仍然落在原来的小节线上.

- 交叉淡化缺省 20ms; 给 0 就是直接对接, 会听到 click
- 剪完必须复测: 测出的 BPM 与首拍相位要与源音乐一致(1 BPM 与 40ms 内), 小节数等于各段小节数之和
- 相似度只是线索, 剪完要试听接缝那 2 秒
- 许可与署名按 `content-and-rights.md` 走, 用户提供的音乐要记进 `credits.md`

## 音效层 (可选, 素材由用户提供)

本技能的配乐是全代码合成的, 音效不自产, 由用户提供素材, 再用 `scripts/sfx.py` 按 cue 表混成一条轨:

```
python scripts/sfx.py audio/cues.json audio/sfx.wav --duration 108
```

两条纪律:

- **稀疏**: 每次转场一个 whoosh, 揭晓与反转各一个关键击, 每屏不超过 1 到 2 个. 用合成噪声当音效并且数量一多, 观众听到的只有噪声
- **加完必须重跑响度验收**: 音效轨混进配乐后, 集成响度仍要在 -16 到 -14 LUFS, 真峰值不高于 -1.0 dBFS; 同时 `check_audio.py` 的拍上/拍间能量比会被转场音效抬高, 要重新看一遍

混音命令的形状是 `[配乐][音效]amix=inputs=2:normalize=0`, 换音轨不需要重渲画面, 用 `-map 0:v -map 1:a -c:v copy` 即可.

## 换风格时的音色替换

- 换燃向: 把 `soft_kick` 换 `kick`, `rim` 换 `snare` 加 `clap`, 加 `hat` 与 `shaker`, `sub_bass` 换锯齿贝斯, BPM 提到 120 到 128
- 换极简: 删掉全部鼓, 只留 `piano` 单音与 `pad`, 和弦循环拉长到 16 小节
- 换芯片音: 正弦换方波, 加极短衰减, 加噪声底鼓, 禁用混响
- 换电影感: 删鼓, `pad` 换长弦乐, 混响尾巴加到 3s, 加低频隆隆

## 常见错误

- 只用白噪声做打击乐, 高频占比必然过半, 听感一定刺耳
- 低音写在根音下方八度又开大声, 低频占比会冲到 70%
- 忘记压缩, 电平忽大忽小, 观众要不停调音量
- 混响 IR 不低通, 混响把高频铺满全片

## 管弦乐编排 (推荐路线)

### 音色库

| 音色 | 实现要点 | 用途 |
|:---:|:---|:---|
| `strings` | 五路失谐锯齿除以五, 5Hz 颤音, 慢起 0.3s, 低通 2.6kHz | 全片和声底 |
| `horn` | 锯齿加饱和, 低通 1.4kHz 叠 0.9 到 2.2kHz 共振峰 | 对位长音 |
| `clarinet` | 只堆奇次谐波 (1,3,5,7) 加微量气声 | 主奏, 空而暖 |
| `flute` | 正弦加二次谐波与 1.5 到 4.5kHz 气声 | 主奏, 明亮不刺 |
| `harp` | 四层谐波拨弦, **衰减必须短于 1 秒** | 琶音装饰 |
| `pizz` | 三层谐波加 0.12s 衰减, 带通到 3.2kHz | 拍点地基 |
| `stacc` | 短弓断奏, 8ms 起音 85ms 衰减 | 八分音符固定音型 |
| `timpani` | 低频加五度泛音与噪声击打, 1.7s 衰减 | 小节头 |
| `choir` | 三路失谐加三个共振峰, 慢起 0.5s | 全奏段最底层 |
| `cymbal_swell` | 噪声带通随时间上移, 2s 渐强, 电平压到 0.2 | 段落切换前 |

### 编排骨架

1. 四小节一个和弦循环, 和声用自然小调 (i, VI, III, VII)
2. 弦乐群每小节一个和弦, 只作底, 电平压到很低
3. 竖琴铺八分音符琶音, 琶音型每 4 小节换一种 (上行, 上下行, 分解, 下行)
4. 主奏按乐句换乐器: 长笛, 单簧管, 圆号轮换, 音区可整体升八度
5. 旋律用动机加变奏: 四小节一个动机, 按乐句计划取 A, A, B, A 的变形并做级数平移
6. 拨弦落满四个拍点, 1 与 3 拍加重, 这是拍点的地基
7. 弦乐断奏铺八分音符, 拍上重音, 让连奏的底子有脉冲
8. 定音鼓落在小节头, 只在有鼓的段落
9. 每 4 小节句首加一枚竖琴或钟琴, 每个切点前 2 秒起滚镲
10. 力度弧线: 每个切点前 2.4 秒从 0.86 渐强到 1.0, 切点后 0.9 秒回落到 0.88

### 按切点分段的配器表 (避免单调的核心)

把整片**按切点**切段, 每段取一组独立的乐器组合与力度, 而不是全片一套配置跑到底:

| 段 | 弦乐 | 竖琴 | 主奏 | 对位 | 拨弦 | 定音鼓 | 人声 | 音区 | 力度 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 引子 | 有 | 有 | 无 | 无 | 无 | 无 | 无 | 0 | 0.62 |
| 1 | 有 | 有 | 长笛 | 无 | 有 | 无 | 无 | 0 | 0.74 |
| 2 | 有 | 有 | 单簧管 | 长笛 | 有 | 轻 | 无 | 0 | 0.82 |

取用规则 (由 `orchestra.py` 的 `seg_bounds` 与 `row_of_seg` 实现):

- 第 0 段固定用引子行, 其余各段在余下九行里**循环**取用
- 切点数量不足九段时, 引擎把最长的段继续对半切开, 直到段数够用; 于是任何片长都不会整片落在同一行上
- 段名 (引子/对比/全奏/回落/收束) 是按参考片的十段结构起的; 段数超过十段时循环体的名字不再对应位置, 只看乐器组合与力度两列
- 每次合成都会打印"段号, 起止秒, 取自表行, 主奏, 拨弦, 定音鼓, 力度", 与"每段起止帧必须核对"同理: 全部段落取到同一行就说明层次没了

**适用范围 (旧版的缺陷就在这里)**: 旧版按固定小节号查表, 表末行的区间是 `(43, 999)`, 第 43 小节之后全部落到末行, 而末行的拨弦系数是 0.
参考片 108 秒 / 45 小节正好填满那张表, 所以看不出问题; 480 秒的片有 200 小节, 后 78% 的段落完全没有节奏层.
同一段 480 秒素材的前后对照 (同一台机器, 同一套参数, 只换引擎版本):

| 素材 | 版本 | 折叠包络起伏 | 拍上/拍间能量比 |
|:---:|:---:|:---:|:---:|
| 480 秒全片 | 旧版 (按固定小节号取表) | 0.17 | 1.27 |
| 480 秒全片 | 按切点分段 | **0.65** | **1.45** |
| 480 秒最后 120 秒 | 旧版 | 0.11 | 1.02 |
| 480 秒最后 120 秒 | 按切点分段 | **0.65** | **1.49** |

最后两行是这条缺陷的正面证据: 旧版的后段已经听不出拍点 (1.02 倍等于没有脉冲), 按切点分段之后后段与前段一样有节奏层.

### 三条硬教训 (都踩过, 都会毁掉卡点)

**1. 总线压缩的时间常数不能短于 0.3 秒**
实测 `tau=0.10` 时, 压缩器正好跟住打击瞬态并把它压平, 拍上/拍间能量比变成 0.99 (完全无脉冲). 改成 `tau=0.45` 后恢复.
规矩: 需要脉冲的音乐, 压缩时间常数取 0.3 到 0.5 秒, 阈值放宽到 0.22 左右.

**2. 任何"时长不小于小节且每小节都出现"的声部都会变成声墙**
实测对位声部每小节奏 3.6 秒长音时, 该总线 RMS 0.166, 而节奏层只有 0.045, 相差 10 倍, 拍点被完全掩埋 (折叠包络起伏仅 0.10).
改成隔小节出现, 时值压到 1.6 拍, 电平 0.20 降到 0.09 后, 折叠包络起伏回到 0.59.
同一类问题在弦乐群与主奏上也量到过一次: 弦乐总线 RMS 0.061 加主奏 0.109, 持续层合计 0.215, 而节奏层 (拨弦加打击) 只有 0.125, 实测拍点峰值比 1.14, 起伏 0.41.
把弦乐电平 0.16 降到 0.12, 主奏 0.22 降到 0.15 之后, 持续层合计降到 0.165, 拍点峰值比回到 1.39, 起伏回到 0.65.
规矩: 持续层总 RMS 必须低于节奏层, 且对位声部要稀疏.

**3. 长衰减拨弦会把琶音糊成连续声**
竖琴衰减 1.8 秒时, 八分音符琶音互相叠成一片, 折叠包络几乎水平.
规矩: 装饰性拨弦的衰减压到 1 秒以内, 且拍上与拍间要拉开电平差 (实测 0.20 对 0.06).
节奏地基的拨弦也一样: 衰减 0.40 秒时尾巴一直盖到拍后 0.3 秒的拍间量测窗, 把拍点峰值比压在 1.30.
把地基拨弦的衰减压到 0.32 秒, 拍上加重 (0.95 提到 1.05), 反拍八分音符从 0.24 压到 0.10 之后, 拍点峰值比回到 1.39.

### 低音音区

拨弦低音写在 110 到 220Hz 区间最稳. 沉到 A1 (55Hz) 时小喇叭完全听不到拍点, 手机上只剩糊.

## 折叠包络法 (验证脉冲的最可靠手段)

把整首曲子按拍长折叠, 看一个拍周期内的平均包络形状. 这是判断"能不能感觉到拍"最直接的指标, 比自相关与拍点峰值比都更贴近听感, **它是主判据**; 拍点峰值比是辅助判据, 且必须按引擎分档:

```python
hop = int(0.02 * sr)
env = np.array([np.abs(a[i:i+hop]).mean() for i in range(0, len(a) - hop, hop)])
ph = (np.arange(len(env)) * 0.02 % BEAT) / BEAT
idx = np.clip((ph * 20).astype(int), 0, 19)
prof = np.array([env[idx == k].mean() for k in range(20)])
prof = prof / prof.mean()
print(prof, "起伏", prof.max() - prof.min())
```

判据: 峰值应落在相位 0 附近, 起伏大于 0.35 才算有明确脉冲.

实测对照:

| 版本 | 折叠包络峰值 | 起伏 | 拍上/拍间能量比 |
|:---:|:---:|:---:|:---:|
| 钢琴版 (music.py) | 2.47 | 1.83 | 1.44 |
| 管弦乐版 按切点分段 (108 秒参考片) | 1.46 | 0.61 | 1.37 |
| 管弦乐版 按切点分段 (480 秒长片) | 1.50 | 0.65 | 1.45 |
| 管弦乐版 旧版按固定小节号 (480 秒长片) | 1.11 | 0.17 | 1.27 |
| 管弦乐版 修好前 | 1.06 | 0.10 | 0.99 |

拍点峰值比那一列都是管弦乐档, 判据是大于 1.3; 钢琴版的 1.44 与键盘电子档的 1.8 不是同一档, 不要横向比较.

## 单调性指标 (RMS 起伏倍数)

按 10 秒一段统计 RMS, 用最大比最小:

| 版本 | 每 10 秒 RMS 起伏 | 谱心范围 |
|:---:|:---:|:---:|
| 钢琴版 | 1.30 倍 | 1045 到 1488 Hz |
| 管弦乐版 | **4.02 倍** | 249 到 385 Hz |

判据: 起伏倍数大于 2.0 才算有层次. 提升办法就是十段式配器表加力度弧线, 让每段的总电平与音色都不同.

## 管弦乐版的频段目标

| 指标 | 实测 | 说明 |
|:---:|:---:|:---|
| 20 到 90Hz | 15.9% | 管弦乐不需要电子乐那么重的超低 |
| 90 到 300Hz | 48.4% | 大提琴与低音提琴的基频区 |
| 0.3 到 0.8kHz | 29.7% | 温暖区, 越高越厚 |
| 2 到 6kHz | 0.9% | 刺耳区, 管弦乐天然极低 |
| 谱心 | 317 Hz | 偏暗是刻意的 |

若觉得发闷, 按顺序调这三个旋钮: `air_noise` 电平 (0.010 到 0.025), `warm_master` 的 `cut1_amt` (0.28 降到 0.18), `lpf` (6000 提到 8000). 不要直接加高频架提升, 那会立刻变刺耳.
