# 任务路由 (先判断该不该用本技能)

接到视频任务时先看这一页, 再决定用哪条路线. 判断错路线的代价比技术细节写错大得多: 本技能的画面与音乐全部由代码算出, 不吃素材与剪辑, 换成剪辑类或生成类的题材就会处处别扭.

## 一, 分流表 (按题材与交付形态)

| 交付形态 | 走哪条路线 | 为什么 |
|:---|:---|:---|
| 逐帧代码画面: 数据动画, 排版片, 片头片尾, 印刷与 riso, 3D 点云, 需要可复现与量化卡点 | **本技能** | 画面与音乐全代码生成, 不依赖素材库与剪辑软件, 判据全部可量 |
| 已有素材要剪: 长视频转短视频, 直播切片, 多轨剪辑, 素材库重剪 | 对话式剪辑器 (如 OpenChatCut, https://github.com/0xsline/OpenChatCut/) | 本技能不导入素材, 也不做多轨时间线编辑 |
| 科普讲解片且接受 Node 渲染链 | knowledge-video (https://github.com/Win-Hao/knowledge-video/) | 它的六步主循环与音乐剪辑工具链更贴"配乐已存在"的场景 |
| 需要 40 种以上成品风格与导演方法论, 含配音与字幕 | lemo-opuscar (https://github.com/lemomo-ai/lemo-opuscar/) | 43 种风格各带样片与实现指导, 走无头浏览器, 自带 TTS 与拟音 |
| 指定某一种风格吃透 (动力学排版或手绘卡通) | opus-video-skills (https://github.com/tuzhechen2005/opus-video-skills/) | 单风格深做, 风格指南与运动词汇表很完整 |
| 已经在用 Remotion 生态, 只要一份规则手册 | remotion-skills (https://github.com/buainoai/remotion-skills/) | 它是框架用法规则库, 不含流程与验收 |
| 动态图形短片, 且希望与本技能同构的工程组织 | RuiC-motion-reel (https://github.com/HRuiCcc/RuiC-motion-reel/) | 同为 Python 加逐帧渲染, 可互相参照工程划分 |

## 二, 友情链接各家的能力边界 (本次审计结论)

| 路线 | 强在 | 边界 |
|:---|:---|:---|
| 本技能 | 全代码, 零素材依赖; 程序化配乐与拟音; 印刷与 3D 点云路线; 九阶段验收与量化判据; 受限沙箱下可用 | 不导入素材, 不做剪辑与配音; 画面风格有边界, 不适合写实影像与真人出镜 |
| OpenChatCut | 对话式剪辑与多轨时间线; 30 个内置专项技能; 主观比较写成可复现评分表 | 依赖它的产品与界面, 不是离线命令行工具链 |
| lemo-opuscar | 43 种风格与导演方法论; 一条时间线驱动画面/配音/配乐/拟音/字幕; 采样音源库 | 走无头浏览器与 GPU, 依赖 Node 与模型下载; 对用户只问一次 |
| opus-video-skills | 两种风格吃透到可复现; 转场与运动词汇表; 子代理分章交接范式 | 风格固定, 不做风格库; 同样依赖无头浏览器 |
| knowledge-video | 用户自带音乐优先; 小节播放表与原始小节锚点; 每条素材给 CC0 来源 | 交给 Node 渲染链; 无代价确认门 |
| remotion-skills | 框架用法规则库, 参数与默认值写法规范 | 无流程, 无风格库, 无配乐方法论, 无验收判据 |
| RuiC-motion-reel | 小节数等于镜头数的结构约束; 音频包络回画面; 单帧成本实测口径 | 交付规格锁死, 与本技能的多画幅多时长口径不同 |

链接是外部项目, 它们的脚本与路径不在本仓库内; 需要用时单独取它们的仓库, 不要把它们的目录当成本技能的一部分.

## 三, 什么时候回来用本技能

出现下面任意一条, 就走本技能, 不要绕去引用外部仓库:

1. **不能联网, 不能装依赖, 也不能启动浏览器**: 本技能默认路线只用 Python 与 FFmpeg, 在受限沙箱下已被验证可跑
2. **没有任何素材, 也不允许引入素材**: 画面逐帧算, 配乐与拟音全代码合成
3. **要可复现与可量化**: 同一帧每次渲出来一样, 卡点, 画质, 响度, 体积都有判据
4. **要做印刷与 riso, 或 3D 点云与隐藏线刻版**: 这两条是别的路线没有的
5. **要一条可交付的音视频成片从头到尾走完**: 九阶段流程自带每阶段产物与两道确认门

## 四, 明显不该用本技能的情况

- 要写实影像, 真人出镜, 实拍素材
- 要剪辑已有素材, 做多轨混剪或字幕重排
- 要配音 (本技能不做 TTS, 只做配乐与拟音)
- 交付形态是工程文件或可交互网页, 而不是一条成片
