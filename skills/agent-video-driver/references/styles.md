# 风格库

本技能不固定风格. 下一节起的牌堆共 31 张, 其中十张给出背景, 调色板, 字体, 运动语法, 配乐音色与适配题材的详细版, 另有十四张来自商用流行风格清单 (逐帧手绘, 等轴2.5D, 扁平矢量, 线条动画, 3D渲染, 形变动画, 贴纸风科普, 赛博朋克HUD, 弥散渐变玻璃拟态, 几何构成包豪斯, 复古Synthwave, 像素风, 液态流动, 综艺花字), 各有一节实现指导; 清单里的"拼贴剪贴"与既有牌 `collage` 拼贴剪纸是同一风格, 共用一张牌, 不重复设牌.
以上全部是**兜底参考**.
配色是用户主权项: 写死的调色板不得替用户默认套用, 必须先按 `SKILL.md` 门一把配色确认下来 (给色相方向让用户挑, 或请用户直接给主色与底色); 用户确实没有偏好时才退回这里的写死色值, 并在分镜表的配色行写明"用户未指定, 取自兜底色板".
用户给了主色时按主色推整套色: 底色取主色的暗端, 强调色 2 到 4 取主色的邻近色相, 并把这几个值都写进分镜表与 `STYLE.md`.
换风格只需改三处: `canvas.ensure_bg(force=True, top=..., bot=..., light=...)` 的背景三色, 调色板常量, 以及运动语法的参数.

## 一, 深空霓虹 (科技燃向)

- 背景: `top=(13,19,36)` `bot=(4,6,13)` `light=(12,22,44)`, 中心偏左上有冷光晕
- 调色板: 青 `#6ED8F5`, 品红 `#F27C9A`, 琥珀 `#F2C46B`, 薄荷 `#7BE0B0`
- 字体: 中文粗体 40 到 104px, 数字用等宽
- 运动语法: 段落切换用硬白闪 `cut_flash`, 切点后 0.22s 内镜头从 1.05 收到 1.0, 元素用 `back()` 回弹入场, 发光用 `gline` 三层叠加加 `bloom`
- 配乐: 120 BPM, 底鼓 1/3 拍, 军鼓 2/4 拍, 锯齿贝斯, 琶音 pluck, 侧链闪避
- 适配: 产品宣传片, 技术发布, 数据可视化燃向剪辑

## 二, 冷调纪录片 (本技能默认推荐)

- 背景: `top=(9,17,35)` `bot=(2,4,9)` `light=(8,19,38)`, 大面积暗场
- 调色板: 柔青 `#6ED8F5`, 暖琥珀 `#F2C46B`, 柔玫瑰 `#F27C9A`, 薄荷 `#7BE0B0`, 紫 `#A89CF0`
- 字体: 标题 38 到 76px, 正文 26 到 36px, 注释 22px
- 运动语法: 段落切换用横向柔光扫过 `cut_sweep`, 镜头 0.5s 缓慢推进, 元素用 `eo()` 缓出, 全局漂移 0.012
- 配乐: 100 BPM, 优先用 `orchestra.py` 的管弦乐配置 (弦乐群打底, 长笛或单簧管主奏, 竖琴琶音, 拨弦拍点, 定音鼓小节头); 想要更轻的听感才用 `music.py` 的毛毡钢琴加 pad
- 适配: 科普讲解, 人物与事件纪实, 深度解读

- 配乐: 弦乐 pad 长音, 钢琴稀疏, 无鼓, 长混响

## 九, 品牌亮色产品片 (品牌与产品发布)

- 背景: 品牌自己的纸白(从品牌色板取, 不要用通用 `#FFFFFF`), 两场暗场用来换气
- 调色板: 品牌色本体做主色, 品牌色板里的语义色(信息蓝, 警告橙, 危险红)做读数, 一档中性灰阶做分割线
- 字体: 高对比衬线做标题, 无衬线做图注, 等宽做读数; 标题骑在发丝网格上
- 运动语法: 位移与不透明度为主, 入场带错帧, 落位带压印; 品牌色满幅的那一场不要给切点爆闪, 纸白到纯白没有余量
- 配乐: 100 到 120 BPM, 弦乐或电钢加轻鼓, 中段抽掉底鼓两拍做 break, 再回来
- 适配: 品牌宣传片, 产品发布, 界面演示

三条纪律:

- 品牌色必须实测, 亮色品牌的暗色版不是另挑一套色, 而是同一组色读到曝光的另一端; 取色方法与来源标注见 `content-and-rights.md` 的品牌素材与品牌色
- 品牌标志必须用真素材, 不要手画; 出现标志时进 `credits.md`
- 亮场上的暗字会被光晕冲灰, 亮场的提亮要用乘法而不是加色, 加色会把同等亮度加到字上, 黑字直接变灰字

## 十, 丝网印与 riso 四色 (独立出版与音乐)

- 背景: 暖米纸, 用 `printkit.paper_field()` 生成而不是纯色 `#F3EEE5`; 纸底的三层(斑块, 细粒, 纤维)缺一不可
- 调色板: 荧光黄 `#FFE04D`, 荧光粉 `#FF5891`, 蓝 `#3F7AD6`, 墨 `#1C2028`; 即 `printkit.INK` 的四色
- 字体: 粗标题字加印刷体小字, 字距收紧; 小字可以略粗糙, 这一档本来就不追求锐利
- 运动语法: 主版线先出, 网点随后补上; 套印偏移平时为 0, 某几拍拉到几个像素再归位; 段落切换直接硬切, 不要溶解
- 配乐: 96 到 120 BPM, 颗粒感的鼓与贝斯, 中频偏暖
- 适配: 科普与文化题材, 独立出版, 音乐与演出海报式片子

四条纪律:

- **画布设成 `SS=1`**: 网点自带抗锯齿, 不需要超采样; 四块版整帧在 SS=1 下约 280ms, 在 SS=2 下约 3100ms, 差约 18 倍. 代价是细线条与小字会略显硬边
- **所有版必须用同一个 `cell`**: 同角度同网线不会出摩尔纹, 同角度异网线会; 网线不一致是最容易犯又最难看出来的错
- 角度错开的真正好处是叠印能出中间调, 不是"避免摩尔纹"; 细节与实测数据见 `print-engine.md`
- 亮场上的暗字会被光晕冲灰, 这一档要基本关掉光晕, 也不要加暗角, 扫描线与色差



## 通用的运动语法 (所有风格都适用)

入场三件套与两条排版纪律, 与具体风格无关, 每个段落都该遵守:

| 项 | 做法 | 引擎入口 |
|:---:|:---|:---|
| 错帧 | 逐字或逐元素延迟 0.04 到 0.06 秒, 整块一起出现最死板 | `stagger(i, n, t, ...)` |
| 缓动 | 入场用 `eo5` 或 `eio`, 落位用 `back` 带一点过冲 | `eo5` `eio` `back` |
| 压印 | 落位瞬间把光晕强度或线宽推过 1, 两三帧后回落, 读起来像按下去 | `impact(x, k)` |
| 字号 | 不要硬写, 指定这一行要占多宽再反解 | `fit_size` `text_fit` |
| 字距 | 按字号的倍数给, 不要写固定像素 | `text(..., track=...)` |

三种风格要收着用: 极简白场与学术图表不做发光也不做压印, 压印只落在位移上; 电影胶片全程缓慢, 错帧间隔可以放到 0.1 秒; 复古终端用硬切不做缓动, 压印改成逐字打字机的停顿.

## 商用流行风格的实现指导 (十四张新牌)

下面十四节各对应一张新牌, 每节只写引擎怎么实现它, 调色板与配乐直接看牌面 (`python scripts/style_lottery.py --list` 或 `STYLE.md`); 通用运动语法 (错帧, 缓动, 压印, 字号反解, 字距) 对它们同样适用.

## 十一, 逐帧手绘 (frame-by-frame)

- 实现: boiling line 是三组定种子微扰位置按 8 到 12fps 轮换, 不是逐帧随机; 折点扰动 1 到 2px, 用 `cv.frame_path` 同帧号取模选组, 保证同帧每次渲出一样
- 线条生长: `c.line` 逐段绘制, 段端点加同一组微扰; 填充色块故意涂出线外 2 到 4px, 涂出方向也要定种子
- 只做加法不做补间: 形态变化拆成若干关键姿态, 帧间切换不做插值, 这是逐帧手绘与矢量动画的根本区别
- 判据: 相邻帧差分在非轮换帧应接近 0, 在轮换帧呈现 1 到 2px 的边缘位移; `preview.py` 字符图核对轮廓稳定性

## 十二, 等轴2.5D (isometric-25d)

- 实现: 场景模块内自封装 `iso(u, v, h)` 返回屏幕坐标, 投影取 `x=(u-v)*cos30*U+OX`, `y=(u+v)*sin30*U-h*U+OY`; 全片共用一个投影函数, 不允许个别元素另设原点
- 三面受光: 顶面取主体色, 左面乘 0.82, 右面乘 0.68, 差 12 到 18 个明度; 光照方向全片固定
- 生长动画: 楼层或部件沿 h 轴逐层 `beat_on` 弹出, 元素滑入沿地面格线 (u 或 v 方向), 不允许离开格线的自由运动
- 判据: 同一地面格点在任意两帧的屏幕坐标差为 0, 等轴投影无透视收敛; 抽两帧核对地面接缝

## 十三, 扁平矢量 (flat-vector)

- 实现: 只用 `c.poly`, `c.disc`, `c.rrect` 画纯色块, alpha 恒为 1, 禁用 bloom, gline, gdisc 一切发光与半透明
- 转场: 段落切换用一块纯色矩形从切点方向扫满全屏, 下一幕从新色块底开始, 底色即转场色
- 网格对齐: 元素位置全部落到画面 12 等分的格线上, 用 `fit_size` 反解字号后也向上取整到格
- 判据: 帧直方图的色数不超过 底色加强调色加两档文字色; 出现渐变像素即不合格

## 十四, 线条动画 (single-line)

- 实现: 全片一条 `curve` 路径, 用 `curve(upto=...)` 控制绘制进度; 段落切换时线头移到画面边缘, 下一幕的新路径从同一边缘接出, 制造"一根线贯穿"的错觉
- 线头: 一个 4 到 6px 亮圆加短拖尾 (`gdisc` 收着用), 是全片唯一允许的发光
- 路径规划: 复杂形体先外轮廓后内部, 每段路径的总长度与该段时长匹配 (行进速度恒定, 约 400 到 700px 每秒)
- 判据: 每段起止帧的路径累计长度差符合段时长, 线头不跳跃; 抽段首段尾各一帧核对

## 十五, 3D渲染 (soft-3d)

- 实现: 走 `three.py` 的参数曲面采样加画家算法; 材质用两档方向光近似 (主光 0.75 加补光 0.25), 不做镜面反射贴图
- 接触阴影: 物体落地处画一圈更深的模糊椭圆 (`imgnp` 的模糊基元), 比长投影更像渲染图
- 镜头: 缓慢环绕或推近, 角速度每秒不超过 6 度; 金属与哑光靠高光锐度区分, 锐高光是金属
- 判据: 用 `preview.py --edge` 核对轮廓连续性, 点云刻版边缘应闭合; 隐藏面不得漏出 (见 `three-d.md` 的画家算法坑)

## 十六, 形变动画 (morph-shape)

- 实现: 两个多边形取相同顶点数, 写一张顶点对应表 (源顶点 i 到目标顶点 i), 中间态用 `lerp` 逐顶点插值, 轮廓线宽恒定
- 节奏: 出发拍与到达拍各占一拍, 中间走 `eio`; 形变完成停两拍给观众看清, 每段只讲一次形变
- 对应表检查: 中间态不自交是硬判据, 抽形变中间帧 (0.3, 0.5, 0.7 三档进度) 用 `preview.py` 核对
- 顶点顺序: 两个多边形都按同一旋转方向 (顺时针或逆时针) 编顶点, 反向会翻转

## 十七, 贴纸风科普 (sticker-science)

- 实现: 贴纸 = 主体加白边 (向外扩 6 到 10px 的白色轮廓) 加同向轻投影 (右下偏移 4px 乘 0.15 透明度); 引出线与圆角标签用 `rrect` 加 `line`
- 贴上动画: `back()` 回弹加 0.5 度以内的旋转入场, 贴上瞬间落一次短促打击点
- 收纳: 讲完的元素收进角落缩略图 (缩小到 0.25 倍加边框), 画面始终只展开当前一步, 避免元素堆积
- 判据: 同屏贴纸数不超过 5 张; 标签文字逐条与事实核查表对账 (内容底线第一条)

## 十八, 赛博朋克HUD (cyber-hud)

- 实现: HUD 框角用直角加缺口 (线段断开 8px 再折角), 数字滚动用 `keyframes` 到目标值, 波形与柱状按拍跳动
- 数据流: 细竖线按拍从上往下扫, 扫过处字符提亮, 用 alpha 梯度实现; 扫描频率与 BPM 对齐
- 故障帧: 关键警报给一次整幅色偏移 (红蓝通道各偏 2 到 3px), 全片不超过 3 次, 平时收着
- 判据: 平时段落的高频占比不超标 (`check_audio.py` 的频段判据), 故障帧只出现在警报拍

## 十九, 弥散渐变玻璃拟态 (aurora-glass)

- 实现: 极光是三团低透明度径向渐变 (蓝紫青各 0.16 到 0.20), 用 `bloom` 大半径低强度近似, 缓慢漂移换位
- 玻璃卡: 白色 0.08 到 0.12 透明度填充, 顶部一条 0.5 透明度内亮边, 底部一条 0.15 内暗边, 外加轻投影; 三件套缺一就退化成半透明色块
- 玻璃卡后面必须有极光经过, 卡片位置随极光排布, 不要把卡贴在没有光的暗区
- 判据: 卡片边缘同时可见亮边与暗边; 极光团不盖过一半画面; 用字符图核对卡片轮廓是双线不是单线

## 二十, 几何构成包豪斯 (bauhaus-geo)

- 实现: 只允许圆, 半圆, 三角, 矩形与黑色粗线 (3 到 6px), 红黄蓝三原色块同屏不超过四块
- 构成重排: 每一小节做一次大规模位移 (元素从一组格位移动到另一组), 一次到位不拖泥带水, 用 `eio` 0.6 拍完成
- 构图均衡: 每帧抽出来要像一张海报, 元素重心大致落在画面三分交点; 写完每段抽一帧自查
- 判据: 帧直方图色数不超过 米白加三原色加黑; 禁渐变禁纹理禁光效, 出现即不合格

## 二十一, 复古Synthwave (synthwave)

- 实现: 透视网格用一组向灭点收敛的横线加放射纵线, 横线按拍向地平线滚动 (间距按 1/距离 缩放); 落日是黄到品红的径向渐变加水平切线
- 霓虹标题: 描边加外发光, 色差分离 (红蓝通道各偏 2 到 3px) 收着用
- 切点: 地平线一次闪光或网格瞬间加速, 与配乐军鼓对齐
- 判据: 网格滚动速度恒定, 不抽搐; 色差偏移量全片一致, 超过 3px 像故障

## 二十二, 像素风 (pixel-8bit)

- 实现: 场景模块里维护一张逻辑分辨率 (例如 240x135) 的 numpy 色板索引数组, 全部图形画在数组上, 输出前用 PIL 的 `NEAREST` 放大到 `W x H`; `cv.configure(SS=1)` 关掉超采样, 抗锯齿是这张牌的禁手
- 移动: 元素按像素网格整格移动, 一次一像素, 禁止亚像素与缓动插值 (位移是阶跃的)
- 色板切换: 昼夜或情绪切换 = 同一数组换一张色板映射表, 帧结构不动; 色板 16 到 32 色
- 判据: 帧放大后直方图色数不超过色板数; 任意两帧的色板并集不超上限; 帧内不得出现中间色

## 二十三, 液态流动 (liquid-flow)

- 实现: metaball 用标量场近似, 场函数是各液滴 `r^2 / d^2` 求和, 阈值 1.0 处为表面; numpy 网格按四分之一分辨率算再 `NEAREST` 放大 (速度), 表面最后再过一次轻模糊 (观感)
- 运动: 液滴落下带挤压回弹 (`impact`), 融合瞬间体积守恒 (一大滴半径按两小滴面积和反解), 融合落在拍上
- 高光: 流体上方一条 0.3 透明度的白色弧形高光带, 始终在上方
- 判据: 融合前后液滴总面积差小于 5%; 全片无硬切, 段落衔接用流体本身的移动完成

## 二十四, 综艺花字 (variety-huazi)

- 实现: 花字 = 超粗描边字 (描边 6 到 10px, 两层色阶: 外深内浅) 加关键词放大到正文 2.5 到 3 倍; canvas 的 `text` 不带描边, 描边用同字多偏移重绘实现
- 节奏: 吐槽贴纸带 3 到 8 度旋转加 `back()` 回弹入场, 停留不超过 1.5 秒就退场; 同屏花字不超过两处
- 音画: 花字出现瞬间配一声镲或鼓 (`audio/sfx.wav` 的 cue 表), 综艺节奏感由音效顶起来
- 判据: 花字常驻不退场即不合格; 同屏计数抽帧核对; 字形体检必须先跑 (花字多为生僻 emoji 替代写法, 先过 `check_text.py`)

### 抽签纪律

```
python scripts/style_lottery.py                     抽一张
python scripts/style_lottery.py --seed 7            可复现
python scripts/style_lottery.py --list              看整副牌
python scripts/style_lottery.py --tone light        只在轻的那一档里抽
python scripts/style_lottery.py --avoid riso-press  排除上一条抽过的
python scripts/style_lottery.py --write <项目目录>  把牌面落成 STYLE.md
```

- 用户没有点名风格, 品牌或参考片时**先抽签再开工**; 抽到哪张做哪张, 不要因为这张不够炫就换牌
- 牌里一半以上是轻的(编辑排版, 工程图, 标本图录, 手绘速写). 轻的做干净了一样好看, 不要每次都上最响的那一支
- 上一条片子抽过的牌用 `--avoid` 排掉, 免得连着两条一个样子
- 只有两种情况跳过抽签: 用户点名了风格或参考片, 或者在改一条已有的片
- 牌面落到项目里的 `STYLE.md`, 收工前扫一眼牌面里的注意那几条有没有踩

## 配乐与风格的对应

配乐默认走 `scripts/orchestra.py` 的管弦乐, 它对十种风格都能配, 且天然满足不刺耳与不单调:

| 风格 | 推荐配器 |
|:---:|:---|
| 1 深空霓虹 | 管弦乐加电子底鼓与琶音, 或用 `music.py` 的燃向配置 |
| 2 冷调纪录片 | 弦乐群加长笛或单簧管主奏, 竖琴琶音, 拨弦拍点 |
| 3 温暖纸感 | 弦乐加竖琴, 木管主奏, 去掉定音鼓 |
| 4 极简白场 | 只留弦乐长音与人声垫, 无鼓无琶音 |
| 5 复古终端 | 换 `music.py` 的芯片音色, 或只保留打字声 |
| 6 学术图表 | 弦乐加钢琴点缀, 无鼓或极轻定音鼓 |
| 7 手绘涂鸦 | 竖琴加木管加轻拨弦, 明亮短促 |
| 8 电影胶片 | 弦乐长音加圆号, 慢速, 长混响, 无鼓 |
| 9 品牌亮色产品片 | 电钢或弦乐加轻鼓, 中段抽掉底鼓两拍做 break |

| 等轴2.5D | 马林巴或拨弦的颗粒感, 生长点落木鱼 |
| 扁平矢量 | 正弦贝斯加掌拍, 干净无混响 |
| 线条动画 | 大提琴长音跟随线头, 落笔处轻拨弦 |
| 3D渲染 | 弦乐 pad 加玻璃质感高频点缀, 极少打击 |
| 形变动画 | 滑音与弦乐 glissando 同步形变, 到位落压印鼓点 |
| 贴纸风科普 | 明亮木管加拨弦, 贴上瞬间短促打击 |
