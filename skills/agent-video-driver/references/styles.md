# 风格库

本技能不固定风格. 下面八种都可直接落地, 每种给出背景, 调色板, 字体, 运动语法, 配乐音色与适配题材.
换风格只需改三处: `canvas.ensure_bg(force=True, top=..., bot=..., light=...)` 的背景三色, 调色板常量, 以及运动语法的参数.

## 一, 深空霓虹 (科技燃向)

- 背景: `top=(13,19,36)` `bot=(4,6,13)` `light=(12,22,44)`, 中心偏左上有冷光晕
- 调色板: 青 `#6ED8F5`, 品红 `#F27C9A`, 琥珀 `#F2C46B`, 薄荷 `#7BE0B0`
- 字体: 中文粗体 40 到 104px, 数字用等宽
- 运动语法: 段落切换用硬白闪 `cut_flash`, 切点后 0.22s 内镜头从 1.05 收到 1.0, 元素用 `back()` 回弹入场, 发光用 `gline` 三层叠加加 `bloom`
- 配乐: 120 BPM, 底鼓 1/3 拍, 军鼓 2/4 拍, 锯齿贝斯, 琶音 pluck, 侧链闪避
- 适配: 产品宣传片, 技术发布, 数据可视化燃向剪辑

## 二, 冷调纪录片 (本技能默认推荐)

- 背景: `top=(9,17,35)` `bot=(2,4,9)` `light=(8,19,38)`, 大面积暗场
- 调色板: 柔青 `#6ED8F5`, 暖琥珀 `#F2C46B`, 柔玫瑰 `#F27C9A`, 薄荷 `#7BE0B0`, 紫 `#A89CF0`
- 字体: 标题 38 到 76px, 正文 26 到 36px, 注释 22px
- 运动语法: 段落切换用横向柔光扫过 `cut_sweep`, 镜头 0.5s 缓慢推进, 元素用 `eo()` 缓出, 全局漂移 0.012
- 配乐: 100 BPM, 优先用 `orchestra.py` 的管弦乐配置 (弦乐群打底, 长笛或单簧管主奏, 竖琴琶音, 拨弦拍点, 定音鼓小节头); 想要更轻的听感才用 `music.py` 的毛毡钢琴加 pad
- 适配: 科普讲解, 人物与事件纪实, 深度解读

## 三, 温暖纸感 (人文叙事)

- 背景: `top=(38,32,26)` `bot=(18,15,12)` `light=(52,42,30)`
- 调色板: 赭石 `#E0A458`, 砖红 `#C4574B`, 墨绿 `#6E8B6A`, 米白 `#F2E8D8`
- 字体: 中文常规体, 标题不要超粗, 字号偏大
- 运动语法: 元素像贴纸一样轻微旋转入场 `back()` 加 2 到 4 度倾角, 纸张纹理用 `motes` 换成噪点色块, 切点用交叉溶解而不是硬切
- 配乐: 90 BPM, 木吉他式拨弦 (正弦加二次谐波), 手鼓低频, 少量弦乐 pad
- 适配: 人文历史, 品牌故事, 手作与工艺

## 四, 极简白场 (产品与设计)

- 背景: 纯 `#F7F8FA`, 只有极淡的径向灰
- 调色板: 近黑 `#111418`, 强调色单色 (任选), 灰阶 `#8A8F98`
- 字体: 中文常规或细体, 大字号, 大量留白
- 运动语法: 只做位移与不透明度, 不做发光, 不做旋转, 缓动用 `eio()`, 切点直接硬切
- 配乐: 极简, 只有钢琴单音与低频 pad, 无鼓, 靠留白制造呼吸
- 适配: 产品说明, UI 演示, 设计理念

## 五, 复古终端 (技术演示)

- 背景: `#050A06` 深绿黑, 叠加极淡扫描线
- 调色板: 磷绿 `#5BE07A`, 琥珀 `#FFC93C`, 白 `#D8F0DC`
- 字体: 等宽为主, 中文用黑体凑等宽感
- 运动语法: 打字机逐字出现, 光标按 2Hz 闪烁, 面板边框按拍呼吸, 元素用 `seg` 硬切不做缓动
- 配乐: 芯片音, 方波琶音, 噪声底鼓, 或干脆只保留打字声
- 适配: 代码与技术演示, 命令行工具, 黑客主题

## 六, 学术图表 (论文与数据)

- 背景: 纯白或极浅灰, 或深色学术风 `#0E1117`
- 调色板: 蓝 `#3B82F6`, 橙 `#F59E0B`, 绿 `#10B981`, 红 `#EF4444`, 灰网格 `#94A3B8`
- 字体: 中文常规, 数字等宽, 坐标轴标签 24px
- 运动语法: 曲线用逐段绘制 `curve(upto=...)`, 数据点按拍依次弹出, 坐标轴先画后标, 禁止发光与缩放
- 配乐: 无鼓或极轻鼓, 以 pad 与钢琴为主, 段落切换用低频 thump
- 适配: 论文解读, 数据报告, 教学课件

## 七, 手绘涂鸦 (轻科普与儿童)

- 背景: 米白 `#FBF7EF`
- 调色板: 马克笔红黄蓝绿, 高饱和
- 字体: 圆体或手写体 (系统缺字体时用黑体加描边代替)
- 运动语法: 线条像被画出来一样逐段生长, 元素入场带轻微弹跳, 可以出现抖动
- 配乐: 尤克里里拨弦, 木鱼, 口哨式正弦
- 适配: 轻科普, 儿童内容, 趣味解释

## 八, 电影胶片 (情绪与回顾)

- 背景: 深褐黑 `top=(22,18,16)` `bot=(8,6,6)`
- 调色板: 低饱和, 暖高光 `#E8D5B7`, 冷阴影 `#4A5568`
- 字体: 细体大字, 字距放大
- 运动语法: 全程缓慢推拉, 切点用黑场过渡, 加颗粒与暗角
- 配乐: 弦乐 pad 长音, 钢琴稀疏, 无鼓, 长混响
- 适配: 年度回顾, 纪念片, 品牌情绪片

## 选风格的方法

1. 看题材: 数据与原理选 2 或 6, 产品选 1 或 4, 人文选 3 或 8
2. 看时长: 30s 以内可以燃 (1), 90s 以上建议稳 (2 或 6), 否则观众疲劳
3. 看信息密度: 演示元素多就用暗背景 (2), 文字多就用浅背景 (4 或 6)
4. 定完风格再定配乐音色, 燃向配打击, 稳重配钢琴与 pad

## 配乐与风格的对应

配乐默认走 `scripts/orchestra.py` 的管弦乐, 它对八种风格都能配, 且天然满足不刺耳与不单调:

| 风格 | 推荐配器 |
|:---:|:---|
| 1 深空霓虹 | 管弦乐加电子底鼓与琶音, 或用 `music.py` 的燃向配置 |
| 2 冷调纪录片 | 弦乐群加长笛或单簧管主奏, 竖琴琶音, 拨弦拍点 |
| 3 温暖纸感 | 弦乐加竖琴, 木管主奏, 去掉定音鼓 |
| 4 极简白场 | 只留弦乐长音与人声垫, 无鼓无琶音 |
| 5 复古终端 | 换 `music.py` 的芯片音色, 或只保留打字声 |
| 6 学术图表 | 弦乐加钢琴点缀, 无鼓或极轻定音鼓 |
| 7 手绘涂鸦 | 竖琴加木管加轻拨弦, 明亮短促 |
| 8 电影胶片 | 弦乐长音加圆号, 慢速, 长混响, 无鼓 |

无论选哪套, 交付前都要过 `audio-engine.md` 的客观判据, 尤其是折叠包络起伏大于 0.35 与 RMS 起伏倍数大于 2.0.
