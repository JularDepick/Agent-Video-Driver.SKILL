# 3D 点云渲染

引擎在 `scripts/three.py`. 它不是三角形光栅化器, 也不打算是.

## 为什么用点云

逐三角形循环在 Python 里太慢, 而"用 numpy 批量处理"在三角光栅化上很难做对: 三角形大小不一, 边界还要插值重心坐标. 点云方案把问题换成 numpy 擅长的形状:

```
曲面密采样 -> 投影 -> 按深度排序后散射(远的先写, 近的后写)
```

numpy 对重复下标保留**最后一次**写入, 这正好是画家算法, 遮挡是精确的. 而且密集点云自带轻微颗粒感, 印出来拍出来都好看, 这也是铜版雕刻的原理.

代价是分辨率靠采样密度堆: 掠射角(面几乎侧对镜头)处点会稀, 需要 `soften` 做亚像素模糊.

## 基本流程

```python
import canvas as cv
import three as th

fn = th.knot_tube(tube=0.25, p=3, q=4)                 # 参数曲面
P, N, shape = th.sample(fn, 420, 130)                  # 采样, 法线由偏导数给出
P, N = th.rot_x(P, -0.26), th.rot_x(N, -0.26)          # 旋转要同时作用到法线
P, N = th.rot_z(P, spin), th.rot_z(N, spin)

cam = th.Camera(eye=(0, 0.72, 7.1), target=(0, 0, 0), fov=30,
                w=cv.W * cv.SS, h=cv.H * cv.SS, shift=(0, 26))
cov, lum, depth = th.render(cam, P, N, splat=cv.SS * 2, soften=1,
                            ambient=0.14, key_gain=1.18, rim_gain=0.60)
c.cloud(cov, lum, color=(150, 200, 255), alpha=1.0, depth=depth, fog=0.35)
```

`render` 返回三个缓冲, 尺寸都是 `(cv.H * cv.SS, cv.W * cv.SS)`:

| 缓冲 | 含义 |
|:---:|:---|
| `cov` | 覆盖率 0 到 1, 已按 splat 足迹展开 |
| `lum` | 明暗 0 到 1.2, 由相机空间法线算出来 |
| `depth` | 归一化深度, 可用于空气透视, 也是隐藏线判定的依据 |

**口径**: `cloud` 与 `engrave` 工作在画布像素网格上, **不受 2D 镜头 `cam()` 影响**; 3D 的机位由 `three.Camera` 自己定. 于是"3D 物体跟着 2D 镜头推近"这件事需要自己把 `cam.eye` 或 `shift` 随时间改, 而不是靠 `c.cam()`.

## 法线来自偏导数

`fn(u, v)` 要写成**参数曲面**, 法线用中心差分 `cross(∂P/∂u, ∂P/∂v)` 求. 不需要网格拓扑, 不需要顶点法线插值, 天然光滑.

微小量 `_E = 8e-4` 不要改大: 太大法线会糊, 太小会被浮点噪声放大.

## 相机与尺寸感受

`Camera(eye, target, up, fov, w, h, shift)`. `shift` 是**画面内的平移偏移**, 用来把物体挪到构图位置而不动镜头朝向, 比调 `target` 直观.

物体统一归一化到半径 1.0 (`fit_radius`), 于是投影半径约等于:

```
投影半径 ≈ 1.0 / eye_z * (h / 2 / tan(fov / 2))
```

h=2160 (1080p 的 SS=2 画布) 与 fov=30 时 `f ≈ 4030`, 所以 eye_z=7.1 时半径约 568px. 按这个先算再调, 别试错; `fit_camera(fov, h, want_radius_px=...)` 可以直接反推 eye_z.

## 光照

相机空间的三件套: **key 加 ambient 加 rim**. key 定义在相机空间(光源跟着镜头走), 所以同一个物体的打光在任何机位都成立.

```python
KEY = norm([-0.46, 0.58, -0.67])     # 左上, 朝镜头
lam = clip(n · KEY, 0, None)
rim = (1 - |n.z|) ** 2.3             # 边缘掠射
lum = ambient + key_gain * lam + rim_gain * rim
```

`rim` 是把"平的剪影"变成"有体积"的那一项, 权重不要省. 光照是双面的, 因为莫比乌斯带这类单侧曲面没有"里面"可以剔除.

## 生成器

| 函数 | 形状 | 用途 |
|:---:|:---|:---|
| `mobius(width)` | 单侧曲面 | "只有一面"的隐喻 |
| `knot_tube(tube, p, q)` | (p, q) 环面结扫掠管 | 遮挡关系明确的雕塑, 最上镜 |
| `box_surface(centre, size, front_bias)` | 长方体点云 | 机柜, 堆叠结构 |
| `supershape(...)` | Gielis 超形 | 有机尖刺体 |
| `sweep_ellipse(curve, half_w, half_t, twist)` | 扁椭圆扫掠 | **有厚度的缎带**, 数据可视化 |
| `spiral_ribbon(...)` | 锥面盘旋缎带 | 形体大而好读, 适合当主角 |

## 配方

### 机柜 (box_surface 加面内细节)

前面板的细节**不要用贴图**: 把面板四角做同样的旋转投影, 得到投影后的四边形, 再在**那个平面里**画通风栅, 硬盘位与状态灯. 这样透视是正确的, 而且细节会随旋转动.

`box_surface` 的 `front_bias` 让前面板采样更密, 于是不用网格也能显出栅格.

### 数据缎带 (sweep_ellipse 加真实数据)

宽度函数直接吃数据或音频包络, 长度方向的扭转让它在 3D 里读得出来.

### 刻版 (隐藏线)

```python
vis = th.visible_grid(cam, P, depth, N=N)      # 逐点可见性
runs = th.contour_grid(cam, P, vis)            # 可见段折线
c.engrave(runs, cv.WHITE, w=1.2 * cv.SS, alpha=0.8)
```

`contour_grid` 返回的是**一段段可见折线**, 远的半边自动被挡住, 这就是刻版效果. 不要用整条等参线去画, 那会把背面的线也画出来.

`visible_grid` 有两个判据, 分工不同, 缺一不可:

| 判据 | 作用 | 取值 |
|:---:|:---|:---|
| 背面剔除 | 给了法线 `N` 时直接把背对镜头的点剔掉; 闭合曲面上被挡住的那一半正好就是背面 | 零成本, 实测零漏判 |
| 深度比对 | 处理"正面但被别的部分挡住"的自遮挡 | `tol=0.002`, `neigh=1` |

参数取值实测(环面结细管, 5.5 万点):

| 设置 | 背面漏判 | 正面误挡 |
|:---:|:---:|:---:|
| 只靠深度, `tol=0.01` | 71.9% | 少 |
| 只靠深度, `tol=0.002`, `neigh=2` | 16.8% | 30.5% |
| 加背面剔除, `tol=0.002`, `neigh=1` | 0% | 15.4% |
| 加背面剔除, `tol=0.002`, `neigh=0` | 0% | 9.5% |

三点结论:

- **只靠深度缓冲不够**: 点云在像素级一定留有空隙, 穿过空隙看到的背面会被当成可见; `neigh` 取邻域最小深度能把空隙填上, 但也会把邻近其它部分的最近深度拉进来
- **背面剔除几乎免费**: 有法线就一定要传, 它把"背面漏判"直接压到零
- 表中"正面误挡"里有一部分是**合法的自遮挡**(正面点被另一段挡住), 所以它不会降到零; 判据是趋势而不是绝对值
- 单侧曲面或开放曲面要传 `backface=False`, 否则会把它唯一的那一面剔掉

## 性能

实测在 3840x2160 画布上, 一帧全流程(采样除外):

| 点数 | 采样 | render 带 soften | cloud 合成 | visible_grid | engrave | 一帧合计 |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 5.5 万 | 61 ms | 200 ms | 168 ms | 44 ms | 10 ms | **420 ms** |
| 10.8 万 | 603 ms | 1249 ms | 556 ms | 154 ms | 62 ms | **1361 ms** |

- 一帧的预算里, 3D 渲染通常**不是**瓶颈, 后面的光晕与颗粒才是
- 几何采样结果要**缓存**: 只有旋转是每帧算的, 采样不要每帧重做
- 全画幅运算是主要成本, 所以 `render` 的 `soften`, `cloud` 的合成与 `visible_grid` 的邻域最小值都**只在覆盖率的包围盒内做**; 去掉这个限制会让单帧涨到 2 秒以上
- 5 秒的 3D 段落按 5.5 万点算约 2 分钟, 按 10.8 万点算约 3.5 分钟; 因此 **3D 只用在需要立体感的段落**, 不要全片铺开
- 采样密度与 `splat` 一起决定覆盖率是否连续: `splat` 缺省取 `cv.SS * 2` 才能让点在画布上连成面

## 三条坑

- **掠射角与网点打架出摩尔纹**: 密集点云在掠射角仍留有采样结构, 症状是亮部出现细密波纹(不是噪点). 药是密度加倍加 `render(soften=1)`, 对覆盖率与明暗做一次亚像素模糊
- **零厚度曲面侧视会碎成尖刺**: 带子转到与镜头平行时投影宽度趋零, 相邻采样点散开. 药是用 `sweep_ellipse` 扫一个**扁椭圆截面**(有厚度, 闭合), 不退化了
- **超形在尖刺参数下自交**: 细瓣会走样成点线. 当花饰用就换温和形体; 非要尖刺就把 `n1` 调大并把采样密度提上去
